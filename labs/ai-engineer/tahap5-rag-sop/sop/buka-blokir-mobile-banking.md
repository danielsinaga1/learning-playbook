# SOP Membuka Blokir Mobile Banking dan Internet Banking

Dokumen fiktif untuk latihan.

## Blokir karena salah PIN atau password

Akun terblokir otomatis setelah 3 kali salah PIN atau password. Nasabah dapat membuka sendiri lewat menu Lupa PIN dengan verifikasi wajah dan kartu debit aktif. Bila verifikasi wajah gagal, nasabah datang ke cabang dengan KTP dan kartu debit.

## User ID dinonaktifkan

User ID dinonaktifkan otomatis bila tidak dipakai selama 6 bulan atau atas permintaan nasabah. Pengaktifan ulang hanya di cabang, tidak bisa melalui call center, dan selesai di hari yang sama.

## Blokir karena dugaan penipuan

Akun yang diblokir karena laporan penipuan hanya dapat dibuka setelah investigasi selesai dan disetujui unit fraud. Petugas tidak boleh membuka blokir ini atas permintaan nasabah langsung.
