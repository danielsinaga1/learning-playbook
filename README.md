## Aturan anti-duplikasi

- Topik yang muncul di dua dokumen hanya ditampilkan sekali di jalur belajar, dari versi yang paling lengkap.
  Contoh Go: bab dasar & REST/DB dari *Pemula ke Mahir*; gRPC, message queue, idiom, dan performa dari *Masterclass*.
- Soal yang sama di dua tempat ditampilkan sekali (mis. Two Sum, Valid Parentheses, Group Anagrams, Merge Sort, Binary Search).
- Soal interview advanced yang topiknya sudah ada di Interview Prep (exception handler, N+1, JWT, microservices) digabung
  sebagai "Pendalaman" di jawaban yang sudah ada.
- Kontrak API Financial Tracker hanya ditampilkan sekali per kurikulum.
- Kosakata yang sama di beberapa dokumen English hanya ditampilkan sekali di jalur belajar.
- Dokumen yang merupakan versi baru dari dokumen lama (E-Book Arsitektur Enterprise, Modul DevOps V2) tidak dibuat modul baru:
  hanya bagian yang belum ada di versi lama yang ditambahkan ke modul topik yang sama, dengan judul *Pembaruan …*.
- 23 soal *Coding Interview in Java* yang juga ada di track soal Java tetap ditampilkan (solusinya berbeda) dan diberi
  tautan ke modul lamanya.

## Arsip Sumber: tidak ada isi yang hilang

Dokumen asli boleh dihapus: semua isinya ada di aplikasi. Bagian yang tidak masuk jalur belajar (duplikat, pengantar,
daftar isi, versi ringkas roadmap Web/Mobile, kalimat HTML yang ditulis ulang) disimpan di track **Arsip Sumber**,
satu modul per dokumen. Tiap modul arsip dibuka dengan **Peta bab**: daftar bab dokumen asli beserta tautan ke modul
tempat bab itu sekarang berada. Modul arsip tidak dihitung dalam progres.

Cakupan diperiksa otomatis dengan `tools/docx-import/audit.py` (membaca file asli dengan python-docx, pdftotext, lxml, dan OCR
tesseract untuk gambar di dalam PDF, lalu mencari setiap paragraf, sel tabel, dan baris kode di data aplikasi). Hasil terakhir:
108 file, 53.275 potongan teks, 99,98% ditemukan; sisanya baris OCR yang salah terbaca, satu baris kontak pribadi dari
screenshot profil yang sengaja tidak disalin, dan 2 baris rumus bersubskrip. Rincian per dokumen: [`tools/docx-import/LAPORAN_CAKUPAN.md`](tools/docx-import/LAPORAN_CAKUPAN.md).

PDF yang isinya gambar (slide kode, carousel, catatan tulisan tangan) disalin manual di `tools/docx-import/manual_sources.py`.
PDF teks biasa (e-book, handout, catatan) dikonversi dengan `text2blocks.py` berdasarkan font, ukuran, dan warna latar.
PDF yang padat diagram atau rumus (e-book RAG, cheatsheet Stanford/MIT) juga ditampilkan sebagai gambar halaman,
begitu pula ilustrasi graf di buku Greedy, screenshot di PDF API Testing, diagram Coding Interview, dan slide pola microservices.
Semua gambar ada di `public/media/` dan dimuat saat dibuka.

## Fitur

Navigasi per kurikulum → track → modul, tandai modul selesai, progres per kurikulum/track, mode latihan soal
(Paham / Ulangi + filter, soal coding dengan tombol "Lihat jawaban"), checklist yang bisa dicentang, mode hafalan
kosakata, pencarian global (`Ctrl+K` / `/`, termasuk isi arsip), salin kode, highlight sintaks (Java, Go, TS/JS, Python,
Dart, Rust, SQL, YAML, Docker, Terraform, GraphQL, dll.), tema terang/gelap, tampilan mobile. Progres disimpan di
`localStorage` browser.

Tampilan ruang belajar menggunakan warna hijau tenang, kartu kurikulum, filter status belajar, dan pencarian kurikulum.
Halaman materi memiliki daftar isi, penanda posisi membaca, ukuran teks Ringkas/Nyaman/Besar, mode fokus, serta pembesaran
gambar. Ukuran teks dan mode fokus ikut disimpan di browser. Tautan daftar isi dan hasil pencarian soal menyimpan bagian
tujuannya dalam URL, sehingga tetap bekerja saat dimuat ulang dan menggunakan tombol kembali/maju browser.

URL biasa dalam materi sekarang bisa diklik, termasuk URL di dalam teks tebal/miring. URL dokumentasi yang berpindah
diarahkan ke alamat aktif melalui `src/lib/links.ts` dan `src/data/link-redirects.json`. Beberapa dokumen referensi lama
yang sudah dihapus diganti dengan sumber aktif tentang topik yang sama. Data asli hasil impor tetap tersimpan.

## Cara menjalankan

Paling cepat: ekstrak **`playbook.zip`**, lalu buka **`playbook.html`** dengan Chrome. Folder `media/` harus tetap
berada di sebelah `playbook.html` (berisi gambar halaman dan ilustrasi).

Mode development (butuh Node.js 20+):

```bash
npm install
npm run dev          # buka http://localhost:5173 di Chrome
```

Untuk membuka versi lokal di repo ini, klik **`playbook.html`**; gambar dibaca dari **`public/media/`**.
`npm run build:single` juga memperbarui file tersebut. Untuk dipindahkan ke komputer lain, salin seluruh isi
`dist-single/` lalu buka `index.html`; folder `media/` harus tetap di sebelahnya.

Build:

```bash
npm run build        # dist/ → untuk di-hosting
npm run build:single # dist-single/index.html + dist-single/media/ → bisa dibuka langsung tanpa server
```

Pemeriksaan:

```bash
npm run audit:links              # semua modul, tautan internal, gambar, dan renderer URL
npm run audit:links -- --external # tambah pemeriksaan HTTP referensi eksternal
npm test                         # alur membaca/navigasi di Chrome desktop dan ponsel
npm run test:standalone           # build dan periksa dua versi HTML tanpa internet
```

Pengujian browser membutuhkan Google Chrome. Pemeriksaan HTTP melaporkan situs yang membatasi akses otomatis
(mis. LinkedIn, Medium, dan halaman akun) terpisah dari tautan yang tidak ditemukan.

## Menambah dokumen baru

1. Taruh file di folder sumber (`.docx`/`.pdf` di root atau subfolder; versi ringkas di `alt/`, halaman HTML di `html/`).
   Untuk PDF, isi `"tool"` di `configs.json` (`text`, `greedy`, `canva`, `sheets`, `manual`) sesuai jenisnya.
2. Tambahkan entri di `tools/docx-import/configs.json` (nama file tanpa ekstensi, level heading yang memulai modul, bahasa kode).
3. Tambahkan modul/track di `tools/docx-import/assemble.py` (fungsi `M(...)` per bab, `tracked(...)` per track) dan
   daftarkan dokumennya di `DOC_CUR` supaya ikut diarsipkan.
4. Jalankan, lalu periksa cakupan:

```bash
pip install python-docx pdfplumber lxml pillow   # + poppler-utils & tesseract-ocr untuk PDF
python3 tools/docx-import/convert_all.py /path/ke/folder-sumber
python3 tools/docx-import/audit.py /path/ke/folder-sumber /path/ke/folder-sumber/en /path/ke/folder-sumber/alt /path/ke/folder-sumber/pdf2 /path/ke/folder-sumber/pdf3 /path/ke/folder-sumber/html/*.html > audit.json
python3 tools/docx-import/report.py audit.json > tools/docx-import/LAPORAN_CAKUPAN.md
npm run build:single
```

Tipe blok: `h`, `p`, `list`, `callout`, `code`, `skills`, `cards`, `table`, `steps`, `tags`, `tabs`, `qa`, `vocab`,
`checklist`, `image`, `details` (bagian lipat). Teks mendukung `**tebal**`, `*miring*`, `` `kode` ``, `[link](https://...)`, dan tautan internal
`[judul](#kurikulum.modul)`.
